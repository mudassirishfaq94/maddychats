## Rollout and limitations

- Migration `0055_presence_privacy.sql` adds only `privacy_settings.last_seen_contacts`, defaulting to an empty JSON array with a type check. Existing settings and encryption data are preserved. Do not deploy application code before applying this migration. Rollback application code first; retaining the unused column is safe. Dropping it would discard saved audience selections and requires a separate approved rollback.
- Android adds the CAMERA runtime permission for explicit QR scanning, constrained to the canonical origin and People route. Audio keeps its separate permission path. No new dependency or paid service.
- Device delivery means at least one authenticated recipient device acknowledged receipt. The existing schema has one delivered timestamp, so it does not represent delivery to every group member or every linked device. FCM acceptance, connection/presence and browser rendering are never substituted for an acknowledgment. If a background handler cannot fetch the encrypted envelope, it does not acknowledge; an active client retries later. Background-handler receipt remains subject to platform delivery/execution limits and is not a force-stop guarantee.
- Last Seen policy changes cannot erase information another user previously observed. Admin aggregate operational telemetry remains restricted to authorized MFA-protected admins.
- Call history follows existing notification retention. It contains identity/outcome metadata, never SDP, audio, message plaintext or encryption keys.
- Camera recognition, APK link dispatch, lock/background calling and notification presentation still require physical-device acceptance; compile/JVM/browser tests do not establish those outcomes.
- The only live data mutation in this batch is the explicitly requested, audited admin-role recovery. No production migration, encryption rewrite, credential change or deployment was performed.

Exact CI results, screenshots, commit and APK hashes are recorded after execution in the external verification report. Features are not declared physically verified from inspection or compilation.
